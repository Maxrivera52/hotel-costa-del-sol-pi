Recursos Java y Arquitectura Integrada

3.1. Google Guava
Preconditions, Cache & Immutable

Validaciones defensivas (Preconditions), caché en memoria para catálogo (CacheBuilder) y colecciones inmutables (ImmutableList).

3.2. Apache POI
Reportes Excel (.xlsx)

Generación dinámica de hojas de cálculo corporativas con XSSFWorkbook para exportar inventarios de habitaciones y reportes de reservas.

3.3. Apache Commons
Lang3 & Collections4

Saneamiento de cadenas con StringUtils, generación de códigos únicos WYN-2026-XXXXXX con RandomStringUtils y CollectionUtils.

3.4. Logback + TDD
SLF4J, SOLID y JUnit 5

Auditoría estructurada en consola y archivo rotativo con Logback, principios SOLID con interfaces DAO y pruebas unitarias con JUnit 5 + Mockito.
